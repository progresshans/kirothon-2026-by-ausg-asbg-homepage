02 PROBLEM

해결하려는 문제

  1. 01공지에 행사·마감·준비물이 섞여 있다
  2. 02캡처를 남겨도 직접 옮겨 적어야 한다

03 SOLUTION

해결 방식

공지 입력 → 근거·추천 분리 → 사용자 승인 → rules.check 판정 → 일정·할 일·외부 연동

링크·텍스트·이미지·PDF 공지를 읽어 원문 근거와 AI 추천을 구분한 계획 초안을 만들고, 사용자가 선택·수정·승인한 항목만 일정과 할 일로 저장한다. 승인·소유권·날짜·알림은 `app/chaenggim/rules.py`의 결정적 판정이 확인하고, 그 판정 코드는 직접 만든 Kiro 파워 Tripwire가 스펙 기준으로 감시한다.

  • 공지 입력URL·텍스트·PNG·JPEG·PDF 수집 (intake.py)
  • 근거·추천 구분원문 근거 문구와 AI 추천을 분리 표시
  • 명시적 승인승인 전 초안 유지, 승인 후 일정·할 일 생성
  • 외부 연결 선택Calendar·Tasks·Drive·ICS 내보내기
  • Tripwire 봉인 검사기준 위반 시 최소 반례와 다음 작업 차단
