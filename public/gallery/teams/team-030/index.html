03 SOLUTION

해결 방식

담기 → 맡기기(영속 큐 + 워커 + kiro-cli) → 꺼내보기

메모·URL·이미지에 목적과 결과 형태를 골라 담으면 파일 기반 영속 큐에 쌓이고, 브라우저와 분리된 워커가 kiro-cli headless를 호출해 여섯 경로로 조사·생성한다. 아침에는 완료·부분 완료·답변 필요 상태를 센 브리핑과 HTML·영상·체험 URL·캘린더 일정을 확인한다.

  • 생각 담기메모·URL·이미지와 목적 조합을 양쪽에서 검증
  • 영속 큐 워커브라우저 닫아도 체크포인트부터 재개
  • 여섯 경로개념·아이디어·요약·일정 결과물 생성
  • 아침 브리핑완료·부분 완료·답변 필요 상태 집계
  • 코드 판정출처 응답·아이디어 5개·일정 모호성 검사
