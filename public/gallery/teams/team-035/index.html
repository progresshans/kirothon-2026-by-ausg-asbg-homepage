02 PROBLEM

해결하려는 문제

  1. 01N분의 1은 덜 먹은 사람이 손해
  2. 02품목별 분배 계산이 대표자 몫
  3. 03안내와 입금 대조까지 혼자 처리

03 SOLUTION

해결 방식

품목 금액 ÷ 체크 인원(원 단위 버림) + 공통 항목 비율 분배 + 자투리는 대표자 몫 → 합 = 결제 금액 검증

각자 자기가 먹은 품목을 투표하듯 체크하면 서버가 품목별로 나누고 공통 항목을 비율 분배한다. 확정할 때마다 몫의 합이 결제 금액과 같은지 검증하고, 다르면 확정하지 않는다.

  • 영수증 OCRBedrock으로 품목·수량·금액 초안 추출
  • 투표형 체크먹은 메뉴를 각자 눌러 실시간 반영
  • 자동 금액 계산ShareCalculator가 합계 일치까지 검증
  • 게스트 웹 참여6자리 코드나 QR로 설치 없이 참여
  • 펑 터뜨리기번개 방 삭제 시 하위 기록 함께 삭제
