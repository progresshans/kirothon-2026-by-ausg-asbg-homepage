02 PROBLEM

해결하려는 문제

  1. 01점심·영화·장소 결정이 오래 걸린다
  2. 02다수결은 싫은 후보를 따라가게 된다
  3. 03눈치 때문에 솔직한 선택이 어렵다

03 SOLUTION

해결 방식

거부권 후보 제외 → 좋아요 내림차순 → 싫어요 오름차순 → 동점이면 랜덤

방 코드와 닉네임만으로 모여 각자 후보를 비공개로 제출하고, 카드 단위 좋아/싫어와 거부권 1개로 결론 하나를 정한다. 이름이 같은 후보는 공백·대소문자를 무시해 자동 통합한다.

  • 코드 참여로그인 없이 4자리 코드와 닉네임, 최대 6명
  • 비공개 제출1인 최대 3개 후보와 어필멘트를 1회 제출
  • 중복 통합공백·대소문자 무시, 어필멘트는 모두 보존
  • 거부권 1개싫어요 후보 중 1개를 결과에서 제외
  • 결과 공개두구두구 5초 후 1등·추천인·순위 표시
