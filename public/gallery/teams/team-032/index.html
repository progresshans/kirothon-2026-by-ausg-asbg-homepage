02 PROBLEM

해결하려는 문제

  1. 01기록이 10개 이상 서비스에 흩어짐
  2. 02녹음 3~4시간, 정리에 2~3시간
  3. 03서비스마다 새 구독료와 사용량 제한

03 SOLUTION

해결 방식

기록 → AI 요약 → 문장별 출처 판정 → 사람 승인 → 마크다운 내보내기

필기·사진·PDF·참고자료를 한 세션에 모으고, AI가 문장마다 출처를 붙인 초안을 만든다. 미검증 문장은 표시해 사람이 처리·승인한 초안만 마크다운으로 내보낸다.

  • 블록 필기 편집기입력을 멈추면 자동 저장(sessions.py)
  • 사진·PDF 첨부EXIF 위치 제거, PDF 텍스트 추출
  • 출처 붙은 초안메모·쪽·사진 출처 표시, 미검증 표기
  • 검토 후 내보내기사람이 승인한 초안만 마크다운 저장
  • 녹음 동의 게이트동의 기록 없으면 서버가 두 번 차단
