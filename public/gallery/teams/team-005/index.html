02 PROBLEM

해결하려는 문제

  1. 01검색하는 동안 대화 흐름을 놓친다
  2. 02설명을 읽어도 할 말이 안 떠오른다
  3. 03복사·앱 전환으로 손이 여러 번 간다

03 SOLUTION

해결 방식

드래그 → 선택 영역 읽기 → 위키백과 재검색 → Kiro CLI 생성 → 출처 검증(2-gram ≥ 0.3) → 결과 창

화면에서 텍스트를 드래그하면 UI Automation으로 선택 영역만 읽어 위키백과 검색 후 Kiro CLI로 문장, 예상 질문 답변, 화제 전환을 생성한다. 출처 ID와 본문 2-gram 겹침 0.3 이상을 통과한 항목만 출처로 표시하고, 부족하면 지어내지 않고 부족 상태를 알린다.

  • 드래그 즉시 분석선택 영역만 읽어 커서 옆에 결과 창 표시
  • 메신저 드래그카카오톡·디스코드 복사 대체 경로, 기본 꺼짐
  • 출처 검증검색된 ID + 본문 겹침 0.3 이상만 출처
  • 문장·질문·전환문장 5개, 질문 5개x답변 2개, 전환 3개 이상
  • Kiro 로그인 화면연결 전에는 분석을 시작하지 않음
