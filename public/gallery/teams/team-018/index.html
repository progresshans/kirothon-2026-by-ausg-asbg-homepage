02 PROBLEM

해결하려는 문제

  1. 01위치·사진·결제가 흩어져 못 꺼낸다
  2. 02일기는 노력이 들어 며칠 만에 끊긴다
  3. 03칸으로 안 나뉜 기억은 찾을 수 없다

03 SOLUTION

해결 방식

방문(Visit) → 장소 → 태그 → 하루/여행 → 질문 시 query_sql 조회 + 근거 카드

iOS 방문(Visit) 단위 위치를 모아 장소·7개 닫힌 태그·하루/여행으로 의미화하고, 24시간 도넛과 타임라인으로 보여 준다. 질문은 Lambda를 거쳐 Bedrock이 읽기 전용 뷰에 query_sql만 실행하게 하고, 근거 카드는 앱이 DB에서 다시 조회해 만든다.

  • 자동 방문 기록도착~출발 구간을 입력 없이 모은다
  • 24시간 도넛0시가 위, 하루·주·월·1년 탭
  • 닫힌 태그 7개확신 없으면 비우고 사람 태그 우선
  • 사진·영상 연결촬영 시각·위치로 방문에 자동 연결
  • 물어보기뷰 조회 후 근거 카드를 앱이 재생성
