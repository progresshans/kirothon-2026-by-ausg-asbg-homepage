02 PROBLEM

해결하려는 문제

  1. 01장 본 재료를 잊고 소비기한을 넘긴다
  2. 02먹은 재료를 직접 지워야 목록이 맞는다
  3. 03온라인 장보기에는 종이 영수증이 없다

03 SOLUTION

해결 방식

등록(영수증·주문내역 인식) → 추천(임박 재료 우선) → 요리 → 차감 → 재고 목록

영수증 사진과 온라인 주문내역 캡처를 같은 버튼으로 받아 Bedrock Claude Haiku 4.5가 품목·수량·보관 위치·예상 소비기한을 추출하고, 사용자가 확인한 뒤 재고에 저장한다. 임박 재료 우선 추천과 "요리했어요" 차감, 3일 6끼 식단을 같은 흐름에 묶어 재고 목록을 실제 냉장고와 맞춘다.

  • 장보기 인식영수증·주문내역 캡처 최대 5장 일괄 인식
  • 임박 재료 강조D-day 순 정렬, D-3 이내 재료 강조
  • 요리 후 차감확인 후 트랜잭션으로 1회만 차감
  • 3일 식단6끼 배치와 3일 뒤 남는 수량 표시
  • 이미지 전처리EXIF 반영 긴 변 1568px JPEG 축소
