02 PROBLEM

해결하려는 문제

  1. 01스킬을 하나씩 돌려 대기 시간이 쌓인다
  2. 02문구·가격·링크 누락을 눈으로 대조한다
  3. 03공개 디자인 스킬이 흩어져 고르기 어렵다

03 SOLUTION

해결 방식

URL → 원본 수집 → 지켜야 할 것 25개 → 스킬별 Kiro CLI 동시 실행 → 코드 검사 → 비교 격자

주소 하나를 넣으면 원본에서 지켜야 할 것을 뽑고, 스킬마다 Kiro CLI 프로세스를 따로 띄워 시안을 동시에 만든다. 포함 여부·링크 일치·외부 스크립트·지어낸 숫자를 AI 없이 코드(`src/core/checker.js`)로 검사해 비교 격자에 배지로 표시한다.

  • 원본 수집·캡처제목·버튼·가격·링크 추출, 1440/390폭 캡처
  • 지켜야 할 것종류별 최대 25개, 체크로 검사 대상 조정
  • 동시 실행스킬별 Kiro CLI 프로세스, 동시 1~6(기본 3)
  • 코드 검사포함·링크·외부 스크립트·지어낸 숫자 판정
  • 비교 격자원본 첫 칸 2열 고정, 실제 렌더 결과 표시
