02 PROBLEM

해결하려는 문제

  1. 01자기 전 내일 알람 맞추기를 깜빡함
  2. 02일정이 바뀌어도 알람은 그대로임
  3. 03공휴일·연차에도 루틴 알람이 울림

03 SOLUTION

해결 방식

기상 = min(첫 일정 - 이동 - 준비, 루틴), 취침 = 기상 - 목표 수면, 확인 알림 = 취침 - 2시간

기기 캘린더의 첫 일정과 요일별 루틴 중 이른 시각으로 기상 시각을 역산해 오늘부터 7일치 알람을 자동 등록한다. 공휴일·연차·휴강을 규칙으로 반영하고, 취침 전 확인 알림에서 바로 수정하거나 끌 수 있게 했다.

  • 기상 시각 역산domain/DayCalculator.kt에서 일정·루틴 비교
  • 7일치 선등록alarm/AlarmPlanner.kt, setAlarmClock 사용
  • 취침 전 확인 알림기본 2시간 전, 수정·끄기 버튼 포함
  • 365일 미리보기ui/preview에서 시각·사유만 확인
  • 끄는 방법 선택버튼 또는 폰 흔들기(2초 안 4번)
