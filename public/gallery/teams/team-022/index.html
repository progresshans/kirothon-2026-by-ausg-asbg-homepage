02 PROBLEM

해결하려는 문제

  1. 01매일 같은 안부를 직접 입력해야 한다
  2. 02엄마·아빠가 궁금한 항목이 다르다
  3. 03부모님은 앱 설치와 타이핑이 부담이다

03 SOLUTION

해결 방식

사진+기분 → judge(밥·귀가) → 자녀 확인 → filter_facts(프로필) → compose(받는 사람별) → 요약 본문+링크 → 고정 버튼 답장

사진 1~3장과 기분 버튼 하나를 받아 AI가 밥·귀가만 판정하고, 자녀가 확인한 뒤 받는 사람 프로필에 없는 항목은 코드가 먼저 걸러 모델에 넘긴다. 부모님은 설치 없이 메시지 본문으로 안부를 보고 고정 버튼 5개로 답한다.

  • 사진 판정service.py run_judge가 밥·귀가만 판정
  • 기분은 버튼rules.py normalize_mood, 버튼 5개+직접 입력
  • 항목 필터rules.py filter_facts가 모델 입력에서 제거
  • 본문 요약build_summary로 링크 없이도 안부 전달
  • 버튼 답장remote.tsx 고정 버튼 5개, 설치 없음
