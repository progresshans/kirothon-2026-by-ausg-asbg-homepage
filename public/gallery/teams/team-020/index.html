02 PROBLEM

해결하려는 문제

  1. 01날씨 앱은 기온 숫자만 알려 준다
  2. 02사진에 날씨가 없어 비교가 안 된다
  3. 03옷장 앱은 등록 부담이 크다

03 SOLUTION

해결 방식

사진 EXIF → 촬영 당일 날씨 → |오늘 − 과거| ≤ 3.0°C(없으면 5.0°C 1회) → rule_based_v1 점수 + 체감 피드백

갤러리 사진의 EXIF에서 촬영 시각·위치를 읽고 그날 날씨를 붙여 저장한다. 오늘 기온과 ±3.0°C 이내였던 과거 착장을 rule_based_v1 점수와 근거 문장으로 보여 주고, 체감 버튼 1회로 점수를 다시 계산한다.

  • 폴더 스캔189장 중 착장 169장만 골라 기록
  • 날씨 자동 연결EXIF 시각·위치로 촬영 당일 날씨 저장
  • 유사 기온 추천±3.0°C 후보에 점수와 근거 문장 표시
  • 체감 피드백버튼 1회 저장 후 점수 즉시 재계산
  • 감시·브리핑새 사진 자동 기록, 07:30 하루 1회 알림
